# The Choice — Pack d’assets

Ce pack contient le logo transmis dans la conversation, l’image principale transmise, ainsi qu’une sélection d’images actuellement utilisées sur le site officiel The Choice.

## Dossiers
- `logo/` : logos.
- `hero/` : visuels larges pour la landing et les sections éditoriales.
- `dishes/` : plats et boissons.
- `events/` : visuels lifestyle pour événements, réservation et service.
- `restaurant/` et `gallery/` : dossiers prêts à compléter avec les futures photos de salle.

## Usage conseillé
- `hero/the-choice-table-user.jpeg` : hero principal de la landing page.
- `hero/sharing-table-01.jpg` et `sharing-table-02.jpg` : storytelling, best-sellers, expérience.
- `dishes/*` : menu, catégories, détails plats et carrousels.
- `events/server-dishes.jpg` : service, équipe, privatisation.
- `events/noodles-lifestyle.jpg` : réservation, événements et contenu lifestyle.

## Droits
Les images venant du site officiel restent soumises aux droits de leur propriétaire. Ce pack est prévu pour la refonte du site The Choice. Vérifier l’autorisation d’exploitation avant toute autre utilisation.
